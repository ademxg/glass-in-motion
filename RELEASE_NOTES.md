# Reusable adapter addition

This optional component package adds modular files alongside the existing single-file GitHub Pages studio. It does **not** change `index.html`, and it is **not** an independently developed WebGL renderer.

## Additions
- A dependency-free app-facing adapter with named presets and a simple API.
- Reusable surface CSS with graceful CSS-only fallback.
- Dedicated demo at `/examples/basic/`.
- Documentation and credits.

The live studio at the repository root continues to work as before.
